# Image Assets

Replace these placeholder images with your real Pandav Solar photos before final production launch.

## Required files in `src/assets/`

| File | Used for |
|------|----------|
| `solar-bg.jpg` | Home hero background |
| `service.jpg` | Page banners (About, Services, Contact, Inquiry, FAQ) |
| `instalation.jpg` | Liaisoning service section |
| `ROOFTOP.jpg` | Rooftop EPC service section |
| `WATER-HEETER.jpg` | Solar water heater section |
| `about-man.jpeg` | About page image |
| `new-logo.jpg` | Contact section logo |
| `footer-logo.jpeg` | Footer logo |
| `project-1.jpg` … `project-4.jpg` | Featured projects gallery |

## Public

| File | Used for |
|------|----------|
| `public/solar-energy.png` | Browser favicon |

## Updating project gallery

Edit `projects` array in `src/config/siteConfig.js` with your real locations and import your project images.

## Updating stats

Edit `stats` in `src/config/siteConfig.js` with your real numbers (years, workforce, customers, MW).
